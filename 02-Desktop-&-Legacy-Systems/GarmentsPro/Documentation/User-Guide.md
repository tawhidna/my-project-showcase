# GarmentsPro – User Guide

## 1. Introduction

This guide provides a structured reference for users reviewing and working with the GarmentsPro application.

GarmentsPro is a Visual Basic 6.0 desktop application for garment manufacturing business operations and reporting. The supplied project presentation demonstrates screens and report options relating to capacity planning, sample planning, export order booking, order allocation, production follow-up, sewing and cutting status, shipment information, and MIS reporting.

The presentation does not show every data-entry screen or interaction step. Accordingly, this guide explains the documented functional areas and gives a safe general approach to using report-selection screens. Exact button names, mandatory fields, validation messages, and transaction procedures must be confirmed against the running application.

## 2. Before You Start

Before using the application:

1. Confirm that you are authorised to access the application and its data.
2. Start the application using the approved shortcut or deployment method provided by the system administrator.
3. Confirm that the application opens and that its required data connection is available.
4. Use the correct business period and selection criteria when reviewing reports.
5. Do not change or delete business records unless this is part of your assigned responsibility.

The supplied presentation does not document installation requirements, login procedures, user roles, or system configuration. These should be added after checking the actual deployment.

## 3. Application Areas

The presentation demonstrates the following functional and reporting areas:

- Capacity planning and management reports
- Sample planning and follow-up
- Export order booking reports
- Order allocation planning reports
- Order-wise production and process follow-up
- Sewing and cutting status reports
- Shipment information reports
- MIS reports, dashboard, and sewing production chart

The menu names and navigation paths should be recorded from the live application rather than inferred from the presentation images.

## 4. General Report Usage

The following procedure is a general guide for report-selection screens. The exact controls and sequence may differ between reports.

1. Open the relevant functional area from the application menu.
2. Select the required report option.
3. Review the available selection fields.
4. Enter or select the required criteria, such as buyer, order number, style, merchandiser, department, floor, line, month, year, date range, season, or ship-date range, where those fields are available.
5. Check the selected criteria before running the report.
6. Use the report-generation or preview control provided by the application.
7. Review the output and confirm that it matches the intended business selection.
8. Print or export the report only if the relevant option is available and you are authorised to do so.

Do not assume that every report supports every filter listed in this guide. Use only the fields displayed by the selected report.

## 5. Capacity Planning and Reports

The presentation includes monthly and weekly capacity views, buyer summaries, booking reports, a monthly booking and order report, a dashboard, and a sewing production chart.

When reviewing a capacity report:

1. Open the capacity or management reporting area.
2. Select the required capacity report.
3. Choose the available period and business grouping.
4. Where supported, review buyer, brand, department, country, merchandiser-head, or product selections.
5. Generate the report and review the displayed capacity and booking information.

The presentation does not specify the capacity formula, unit of measurement, utilisation calculation, or rules for available capacity. Refer to the approved business rules for those details.

## 6. Sample Planning Reports

The sample planning report list includes buyer-wise, order-wise, style-wise, sample-type-wise, and merchandiser-wise status reports. It also includes not-done status, history, cut-plan, sewing-date, print/embroidery sent-date, sample deadline, and sample sending-status reports.

To review sample planning information:

1. Open the sample planning report area.
2. Select the report that matches the required review.
3. Provide the available buyer, order, style, sample type, merchandiser, or date criteria.
4. Run the report.
5. Review the status and date information shown in the output.

Use the application's own status definitions when interpreting sample progress.

## 7. Export Order Booking Reports

The presentation lists export order booking reports by month, season, buyer, ship-date range, merchandiser, style, and department.

To review export order booking information:

1. Open the export order booking reporting area.
2. Select the required report view.
3. Enter the available period or business filters.
4. Where applicable, select the required sorting option.
5. Generate and review the report.

Check the selected date basis carefully. A booking-month report and a ship-date-range report may represent different business views.

## 8. Order Allocation Planning Reports

Two order allocation plan-status views are listed:

- Date-range and floor-wise order allocation plan status
- Date-range and buyer-wise order allocation plan status

Select the appropriate report and enter the available date range and other displayed criteria. Review the resulting allocation status using the application's displayed labels and values.

The allocation method and planning rules are not specified in the presentation.

## 9. Production and Order Follow-up Reports

The presentation includes order-wise reports relating to:

- Production status and order sheet details
- Yarn issued status
- Fabric requirement status
- Knitting plan and production
- Collar and cuff production
- Dyeing plan and production
- Laboratory test status
- Dyeing delivery status
- Accessories and CAD status
- Sewing-line production
- Cutting production by order and size
- Shipped and unshipped orders

To review an order:

1. Open the relevant order or production reporting area.
2. Select the report required for the process being reviewed.
3. Enter the order number or other available selection criteria.
4. Run the report.
5. Review the information returned for the selected order.

Where multiple reports exist for one order, use the relevant report for each process area. Do not treat a report as proof that a process transaction has been completed unless its displayed status and business definition confirm that interpretation.

## 10. Sewing and Cutting Reports

The presentation lists sewing status and cut-to-slip reports by date and floor, month and year, order number, and line number.

Select the report that matches the required operational view. Enter the available date, period, floor, order, or line criteria and review the output.

The presentation does not define the production quantities, efficiency formulas, target calculations, or cut-to-slip business rules.

## 11. Shipment Reports

The shipment reporting area includes buyer and season, buyer/season/department, ship-date range and buyer, shipment summary status, and shipment details reports.

To review shipment information:

1. Open the shipment reporting area.
2. Select the required shipment report.
3. Enter the available buyer, season, department, or ship-date range.
4. Generate the report.
5. Review the summary or detail output, depending on the selected report.

Confirm the ship-date selection and reporting period before using the report for business decisions.

## 12. MIS Reports and Dashboard

The presentation demonstrates capacity summaries, buyer summaries, booking reports, monthly booking and order information, a dashboard, and a sewing production chart.

Use the report or dashboard that matches the required management review. Check the displayed period and grouping before interpreting the results.

The presentation does not provide KPI definitions, calculation formulas, refresh schedules, or data-refresh controls. These should be documented from the actual application and approved reporting definitions.

## 13. Good Operating Practices

- Select the correct buyer, order, style, period, and department before running a report.
- Review date ranges carefully, especially where booking dates and ship dates are both used.
- Use the appropriate report level: buyer, order, style, floor, line, or department.
- Check report headings and selected criteria before printing or sharing output.
- Handle buyer, order, employee, supplier, and shipment information as confidential business data.
- Do not share screenshots or reports containing live company information in a public repository.
- Report unexpected results or application errors to the authorised system administrator.

## 14. Troubleshooting and Support

The supplied presentation does not contain an error catalogue or troubleshooting procedure. For an issue:

1. Record the screen or report being used.
2. Note the selected criteria and the period.
3. Record the exact error message, if one appears.
4. Note the steps immediately preceding the issue.
5. Contact the authorised application or database support person.

Do not modify database records or application configuration to resolve an issue unless you are authorised and have an approved recovery procedure.
